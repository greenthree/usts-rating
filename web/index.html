系统架构理念：Data-as-Code

本系统专为苏州科技大学 ACM/XCPC 集训队设计，完全采用 Data-as-Code（纯静态无后端服务器） 架构。所有选手花名册（data/users.csv）和标准化赛事榜单（data/contests/*.json）均直接托管在 Git 版本控制仓库中。每当有新比赛录入并推送到主分支时，GitHub Actions 自动化流水线会依次执行严格的数据规范校验（validate_data.py）、完整的单元与回归测试（pytest）、NumPy 向量化加速的多人算分引擎（recalculate.py），并将聚合完成的纯静态看板自动化发布至 GitHub Pages。无需运维任何数据库和后端服务，数据完全透明、可追溯、零成本维护。

双轨制积分架构 (True Rating vs Display Rating)

为彻底解决新队员（尤其是大一萌新）初始参赛单场分值剧烈震荡、小号虚高的问题，系统引入参考 Codeforces 的双轨积分制度：

  • 底层真实战力分 (True Rating)：所有数学计算和期望胜率预测完全基于无偏的真实战力分。无公开外部竞赛记录的新生初始基准分为 800；已有外部公开 XCPC-Elo 战绩者填入其实际分值。
  • 前端展示分 (Display Rating)：前端排行榜和所有徽章展示采用显示分，计算公式为 Display = max(0, round(True + Offset))。

赛前队伍战力合成与 Multi-Player Elo 结算

1. 队伍战力合成公式 ($R_{team}$)

校内组队队伍由 $k$ 名成员组成时，采用与 XCPC-Elo 官方完全对齐的对数幂平均模型 (log-power-mean)，将已有参赛历史的队员实力通过胜率胜力值做对数平均：

R_team = 400 · log10( (1 / k_rated) · Σ 10^(R_i / 400) )

该模型保证队伍战力平滑合理，未参赛新人不拉低种子预期，若全队均为新人则以萌新基准 800 分起跑。外部队伍直接使用其标注的 external_elo（缺省默认为 1500）作为基准锚点。

2. 期望胜率与二分表现分查找 ($R_{needed}$ 与 $R_{perf}$)

任意两队 $A, B$ 之间，队伍 $B$ 战胜队伍 $A$ 的期望概率为：$P(B > A) = \frac{1}{1 + 10^{(R_A - R_B)/400}}$。队伍 $A$ 的赛前期望种子排名为 $\text{Seed}_A = 1 + \sum_{B \neq A} P(B > A)$。

比赛结束后，队伍 $A$ 获得实际排名 $\text{Rank}_A$。引擎在 $[-500.0, 3500.0]$ 区间内进行 50 次向量化二分查找：由实际排名 $\text{Rank}_A$ 反推出队伍实际发挥的队伍表现分 $R_{perf}$；由几何均值目标名次 $m_A = \sqrt{\text{Seed}_A \times \text{Rank}_A}$ 反推出目标所需战力 $R_{needed}$。

3. 动态学习率与个人 Delta 结算

完全对齐 XCPC-Elo 的 Codeforces 动态衰减学习率与个人分差结算机制：

lr_i = 0.6 + 0.3 · e^(-contests_i), ΔR_i = W_contest · (R_needed - R_{i, old}) · lr_i

新选手首场学习率高达 0.9，随场次平滑衰减至 0.6；队员变动直接锚定自身历史积分与队伍目标分之差，使低分队员能快速跟上队伍梯队，高分队员自动达到均衡平台。

4. 校内外赛事权重与校内赛零和校准

  • 校外赛 (EXTERNAL_XCPC, 权重 1.00)：以全国高校顶尖队伍为锚点，校内队伍的积分变动直接吸收外部战力，不进行零和修正。
  • 校内赛 (INTERNAL_SCHOOL, 权重 0.80)：仅校内队员参赛。为防止校内赛事内部产生系统性通胀或通缩，引擎计算所有参赛本校选手的均值漂移 $\mu = \frac{1}{M}\sum_{i=1}^M \Delta R_i$，并在结算时从每位选手扣除该均值：$\Delta R_i \leftarrow \Delta R_i - \mu$，确保 $\sum \Delta R_i = 0$ 恒成立。

退役判定机制

为保证排行榜的真实活跃度和梯队选拔参考价值，系统内置自动退役判定规则，满足以下任一条件即判定为退役（is_retired = true）：

  • 毕业退役：2022 级及更早入学（已毕业）的队员自动判定为退役；
  • 超期退役：选手最近一场有效参赛记录距今超过 2 年（730 天），或已入队满 2 年但从未参加任何一场计分赛；
  • 主动退役：集训队花名册档案明确标注非活跃（is_active = false）。
